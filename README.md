# fakeOTLBot — v3 rework

Изменения v3:
- Telegram Stars отображаются как `Stars`, без `XTR` в пользовательских сообщениях.
- Для Stars хранится Telegram username получателя.
- В сообщениях сделки явно отображаются продавец/получатель и реквизиты оплаты: TON-кошелек, банковская карта или username Stars.
- После подтверждения тестером передачи товара покупатель получает сообщение о том, что товар передан гаранту/поддержке и должен оплатить сделку по указанным реквизитам; после проверки оплаты поддержка передаст товар.
- После тестового подтверждения оплаты продавец получает уведомление о заявленной оплате.
- Старые сделки с валютой `XTR` распознаются как Stars.
- Исправлено отображение валюты в админ-панели.
